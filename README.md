# 프레시킷 (FreshKit) - 프리미엄 밀키트 전문 소개 및 정기구독 플랫폼

셰프의 노하우가 담긴 프리미엄 밀키트를 간편하게 탐색하고, 나만의 맞춤형 식단을 정기 구독할 수 있는 React 프로젝트입니다.

## 주요 기능
- **밀키트 카탈로그 & 카테고리 필터**: 한식, 양식, 캠핑/여행, 헬스/다이어트, 1인 가구 등 목적별 탐색
- **추천 이미지 4종 완벽 반영**: 여행/야외, 고급 셰프 요리, 건강/샐러드, 이색 다이닝 밀키트 배치
- **맞춤 밀키트 추천 퀴즈**: 3단계 질의응답으로 개인별 최적 밀키트 추천
- **레시피 & 스마트 타이머**: 밀키트별 요리 과정 안내 및 인터랙티브 타이머 simulator
- **장바구니 & 정기구독 시뮬레이터**: 주간 배송 수량, 구독 할인 계산 및 결제 체험
- **새벽배송 카운트다운**: 당일 새벽배송 마감시간 실시간 표기

## 실행 방법
```bash
npm install
npm run dev
npm run build
```
